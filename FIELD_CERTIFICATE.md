# Полевой сертификат FLOS desk (Wiren Board)

Приёмка ритуала на живом щите. Не заменяет stamp WB — это passport объекта + чеклист.

## Автопроверка на столе

1. Откройте `http://<щит>:18081/`
2. **Сертификат** (рядом с «Обновить»)
3. Зелёные пункты = готово к сдаче локального контура

API: `GET /runtime/field-cert` → `checks[]` + `passport`.

## Ручной проход (электрик)

| # | Шаг | Ожидание |
|---|-----|----------|
| 1 | Шина | «Шина ок», топики > 0 |
| 2 | Разметить | ≥1 имя в комнате, без сырого шума в комнате |
| 3 | Типовые | Карточка → параметры понятны → «На стол» |
| 4 | Залить имена | Имена на щите / form_logic_os |
| 5 | Залить сценарии | Правила сработают (кнопка / климат) |
| 6 | Журнал | Виден revision; откат доступен |
| 7 | Версия | `lan-desk-*` в шапке = ожидаемый tip |
